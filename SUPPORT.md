# Support

Keyina is currently a source-first, pre-release project. There is no stable installer or guaranteed support window yet.

## Where to ask

- Use a GitHub issue for reproducible bugs and focused feature requests.
- Use a GitHub discussion for usage questions, design ideas, and broader feedback when Discussions are enabled.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

## Before requesting help

Please include:

- Windows version and architecture.
- Keyina commit or release version.
- Target application and version.
- Exact physical keystrokes, expected text, and actual text for typing issues.
- The command that failed and the complete non-sensitive error output for build issues.
- Whether the same behavior occurs in Notepad.

Remove credentials, private documents, personal information, and unrelated logs before posting.

## Current limitations

- No signed installer is published yet.
- Elevated applications and raw-input software may require compatibility work.
- Speech requires an explicit Speechmatics credential and remains optional.
- Manual compatibility coverage is still expanding across Windows applications.

See [README.md](README.md) and `docs/compatibility/` for the latest verified scope.
